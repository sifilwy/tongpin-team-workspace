# 空白时间段拖动新建日程

个人日程的日期列支持按住鼠标左键，在空白时间区域上下拖出时间段。拖动时显示时间范围，松开后打开新建任务框，自动填入日期、成员、开始与结束时间。用户填写名称并保存后才新增任务。

时间按 15 分钟对齐，最短 15 分钟，限制在日历 07:00–22:00 范围内。向上拖动同样有效。移动少于 4 像素不创建；Esc、指针取消或捕获丢失取消选择。现有任务卡片不触发新建。全员视图的新建默认归属当前登录成员。此交互支持鼠标和笔，触屏仍保留原有滚动及“添加”按钮。

验证：生产构建与 14 项 Node 测试通过；离线浏览器验证拖出 09:00–10:30、保存后的日期和成员、反向拖动、点击阈值、Esc、原有卡片编辑。公网 HTTPS 浏览器在实际日历空白处拖出 09:00–10:30，确认预览及弹窗预填日期时间后取消，未新增业务数据。个人日程和任务复盘回归继续通过。

镜像 `tongpin-team-workspace:20260907-drag-create`；发布目录 `/opt/apps/tongpin-team-workspace/releases/20260907-drag-create`。数据挂载、HTTPS 入口和仅本机绑定的端口不变；上一版容器保留为停止状态的 `tongpin-before-drag-create`。
