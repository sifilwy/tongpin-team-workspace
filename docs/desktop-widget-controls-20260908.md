# 桌面组件关闭与圆点模式

用户反馈缺少明显的关闭及收起入口。原生标题栏增加独立的 − 收起按钮和 × 退出按钮，均有鼠标提示及可访问名称。保留更多菜单和系统托盘出口。

收起后将同一个桌面子窗口缩为 54 DIP 的蓝色笑脸圆点，隐藏网页及标题栏；点击展开，恢复原来的日程位置、大小和网页状态。圆点支持鼠标拖动及右键菜单。拖动后松开不会误触展开。退出时保存日程位置，避免将圆点坐标写成日程坐标。

本次仅修改 Windows 宿主，无网站部署或任务数据更改。

验证：本地编译通过；原生验证流程确认标题栏按钮未被其他控件遮挡，实际按钮事件可以收起为 54 DIP 圆点、恢复原始大小、重复收起展开，以及通过关闭按钮退出进程。HTTPS 日程同步、周日期切换、15 秒刷新和解除/重新固定继续通过。检查了圆点绘制截图。
