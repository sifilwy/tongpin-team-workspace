# 修复桌面标题栏黑色显示

用户提供的实际桌面截图显示：原生标题栏呈黑色，而下面的 WebView2 日程正常。之前单独绘制 WinForms 控件的截图不能证明它们在 Windows 桌面父窗口中正确合成。

将标题栏及更多菜单改为嵌入程序资源的网页 UI，和日程共同由 WebView2 绘制。收到 UI 就绪信号后隐藏原生标题栏，WebView2 从窗口顶部开始，消除原生标题栏占据的黑色区域。网页消息只接受 HTTPS 本站 `/desktop` 来源及固定命令，不允许任意系统命令或文件操作。网站部署和任务数据均未更改。

实机验证通过：统一页面截图包含浅蓝色标题栏、同屏文字和两个操作按钮；检查按钮命中区域；通过实际网页按钮消息收起圆点、展开、退出；HTTPS 同步和周期刷新继续通过。新版程序已替换并重新启动。使用说明增加了关闭后的本机重新打开步骤。
