# 日历图标及直接拖动

新增自绘矢量日历图标，输出 16–256 像素的多分辨率 ICO，并嵌入程序及桌面快捷方式。图标源为 desktop-widget/icon.svg。

标题栏空白区域直接拖动移动，四条边和四个角直接调整大小，右下角显示斜线把手。无需先切换移动模式。网页通过固定手势消息发送物理像素增量，原生宿主保留桌面子窗口关系并更新边界。按钮及菜单不参与拖动；按 Esc 取消，松开保存位置和大小，兼容原来的两字段位置文件。最小尺寸为 320 × 280 DIP，避免控件挤到不可用。

验证从网页指针事件处理器经过 WebView2 消息桥到真实 Windows 窗口位置、大小，覆盖移动、右下角缩放、取消缩放；同步、收起、展开和关闭验证继续通过。过程中确认了移到工作区边缘时会限制位置，测试采用工作区内的移动量。

本次仅更新本机组件及桌面图标，不变更网站业务代码。其他任务正在修改的 app/page.tsx、app/timeline-fit.css 不包含在本次提交。
