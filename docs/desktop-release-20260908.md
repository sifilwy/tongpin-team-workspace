# xzx 桌面日程

新增 HTTPS 页面 `/desktop`，使用独立的浅蓝灰布局、时钟、周日期选择、当前/下一项安排、当天时间线、完成状态及待安排列表。仅展示网站个人日程中 owner 为 xzx 的条目，不混入团队任务或其他成员。

页面通过已登录会话每 15 秒读取 `tongpin-personal-tasks-v3`，不向任务接口写数据。断网时保留已读取的数据并提示重试；登录失效则清除所展示数据并提示重新登录。跨天时，处于当天视图的日期跟随更新。

生产构建和 16 项自动测试通过；离线浏览器验证 xzx 过滤、日期导航、空状态、待安排和自动只读刷新。已通过公网 HTTPS 登录读取真实日程。2026-09-08 检查时，网站 xzx 的个人任务仅有 1 条，日期为 2026-09-04，因此当前日视图为空，上一周可查看该安排。

发布镜像 `tongpin-team-workspace:20260908-desktop`，目录 `/opt/apps/tongpin-team-workspace/releases/20260908-desktop`，旧容器保留为 `tongpin-before-desktop`。现有任务数据、HTTPS 和内部端口不变。

桌面集成：已准备 `scripts/install-desktop.ps1`，用于创建 Edge 独立窗口快捷方式。独立浏览器资料目录为用户本机 LocalAppData 下的 TongpinDesktop；已通过 HTTPS 完成登录初始化，正常浏览器会话保存在该资料目录，邀请码不在脚本或快捷方式中。

自动创建并打开 Windows 桌面快捷方式的操作被自动审批审查拒绝，返回原因仅为 `blocked by policy`，所以不能声称已经创建或打开了桌面应用。没有重试同一被拒绝操作。项目根目录提供了不含执行命令和凭据的 `同频-xzx桌面日程.url`，用户可以手动放到桌面，以浏览器打开网页版。该 URL 文件使用浏览器自身的登录状态，不保证沿用独立应用资料目录中的会话。
