# 从小组件打开工作台

顶部增加“打开网站 ↗”按钮，更多菜单和系统托盘也提供打开网站入口。恢复底部工作台链接。此前所有 WebView2 新窗口请求都被直接拦截，现在用户点击本站首页链接时交给系统默认浏览器打开，小组件继续停留在 /desktop。

原生宿主始终打开固定地址 https://yanxue-sync.top/，不执行网页提供的任意 URL 或命令，不传递邀请码或会话。若系统未能启动浏览器，托盘提示手动访问地址。网站在浏览器里的登录状态与小组件各自独立。

构建安装包 TongpinWidgetSetup-20260910.exe，更新网页下载链接和 SHA256 清单。本机已通过安装器正常退出旧版、安装新版并重新打开，保留资料和位置，状态为 page-synced、任务栏隐藏。

原生验证通过网站按钮到命令处理的消息链、组件仍停留 /desktop、拖动缩放、独立窗口、同步、非黑屏、圆点与关闭。验证模式记录浏览器启动请求而不实际启动外部浏览器；不将其描述为实际鼠标点击浏览器测试。Windows UI 工具未列出隐藏任务栏的组件窗口，未进行坐标猜测。

发布基于当时生产 20260910-undo/source，仅覆盖下载按钮、新版安装包及清单，保留其他任务发布的撤销功能。镜像 tongpin-team-workspace:20260910-widget-website，旧容器 tongpin-before-widget-website。安装包不包含账号、会话或任务内容。
