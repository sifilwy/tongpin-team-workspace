# 协助人与完成后确认实际产出

新建和编辑任务时，在负责人下方选择一个或多个协助人。协助人只作标注，不改变负责人、任务归属、完成人或金额归属。时间线任务详情也可调整协助人。

金额使用单次金额 × 实际产出次数。新任务的次数可留空，表示待确认，不计算预计收益。标记完成时，有单价但次数未确认的任务会打开确认框：可以填写实际次数后完成，也可以先标完成、次数待确认。待确认的任务不进入金额合计。之后可通过编辑任务修改实际次数，仍只有一个任务。

兼容旧数据：`quantity` 缺失表示旧任务按 1 次计价；新任务使用 `quantity: null` 表示未确认。0 表示已确认实际为零次。旧任务原有金额不变。`amount` 继续保存单次金额；所有金额卡片和汇总通过同一合计函数计算。金额汇总仍只计已完成任务，协助人不分摊。

验证：生产构建、16 项自动测试、离线浏览器完整流程通过，包含次数留空、协助人独立选择、完成时填写 7 次、单价 100 元合计 700 元、只有一个任务且仅计入负责人。公网 HTTPS 浏览器验证新建表单的多选协助人、次数默认留空和 700 元预览，未创建业务任务；原有日程拖动与任务复盘回归继续通过。

发布镜像 `tongpin-team-workspace:20260907-outputs`，目录 `/opt/apps/tongpin-team-workspace/releases/20260907-outputs`。升级前数据备份为该目录的 `data.before`；原容器停用并保留为 `tongpin-before-outputs`。HTTPS、数据目录和内部端口不变。
