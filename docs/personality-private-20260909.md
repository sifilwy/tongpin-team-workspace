# xzx 私人人格改变界面

新增“人格改变”导航，仅实际登录成员为 xzx 时显示和挂载。第一版提供“我想成为怎样的人”“我正在练习的改变”，以及按日期保存行动和感受的记录；支持编辑已有记录。没有填入示例记录或人格判断。

私有文档 key 为 tongpin-personality-xzx-v1。服务端 GET/POST 均在读取文档、返回 revision 冲突内容之前检查会话成员；其他四名成员返回 403，未登录/伪造/注销会话返回 401，禁止通过 body 的 member/owner 绕过。POST 在读取请求体后重新校验会话。GET 仅接受文档白名单，响应不缓存。

内容不写入 localStorage 或 IndexedDB。未保存输入只保留在当前页面内存，切换工作台视图不卸载私有表单；离开或刷新时对未保存内容使用浏览器提示。失效会话会清空可见内容和草稿。保存时读取最新文档并通过 revision 提交，在冲突中保留其他记录；断网显示错误、保留输入，不伪报成功。

校验最多 1000 条记录、每个文本字段最多一万字、有效日期及唯一记录 ID。第一版不提供删除记录、自动打分或人格测评。

验证：生产构建及 33 个 Node 测试通过。权限测试覆盖四名非 xzx 成员读取、正确/错误 revision 写入、伪造身份、未登录/注销、无内容泄露及格式校验。浏览器测试覆盖保存/编辑/重新加载、切换视图保留草稿、断网、冲突保留其他记录、无本地存储、手机宽度、会话失效清空、其他成员不挂载或请求该组件。

公网再次验证 xzx 返回 200，其他四名成员 GET/POST 返回 403，未登录返回 401；非 xzx 不显示入口，xzx 页面正常。线上没有写入测试用私人内容，测试创建的登录会话随后注销。部署基于当时线上 desktop-button/source，生产镜像 tongpin-team-workspace:20260909-personality，旧容器 tongpin-before-personality 保留。
