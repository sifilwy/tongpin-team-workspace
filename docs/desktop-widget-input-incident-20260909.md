# 桌面无法点击：组件已停止，根因待确认

用户反馈桌面两次无法点击。2026-09-09 检查 Windows Application 日志，发现 Explorer.EXE 在本地时间 10:48:45 和 11:11:16 两次崩溃，异常模块 ucrtbase.dll，异常代码 0xc0000409。日志没有直接证明 TongpinWidget 是唯一原因。

组件通过跨进程 SetParent 将 WebView2 宿主及圆点窗口作为 Explorer 桌面的子窗口，并使用指针捕获处理拖动。这种父子关系会关联输入队列，因此组件或其渲染线程异常可能影响桌面输入；需要优先排查这一实现，不能仅凭组件内部截图、网页探测或按钮测试认定桌面稳定。

处理：结束了已确认路径下的 TongpinWidget 进程，确认没有同路径组件进程剩余；Explorer 进程当前报告 Responding=true。没有重启 Explorer、修改 Windows 设置或再次启动组件。已向用户说明风险并询问停止组件后桌面是否恢复可点击。

后续应解除与 Explorer 的直接父子窗口关系，评估独立窗口方案，再验证实际桌面输入稳定性。软件渲染仅处理了此前黑屏，并未证明修复输入或桌面进程崩溃问题。
