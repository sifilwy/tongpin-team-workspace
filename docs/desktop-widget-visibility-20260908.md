# 组件按钮及圆点显示修复

用户反馈圆点消失，无法看到收起和关闭按钮。检查时没有运行中的 TongpinWidget 进程，只有以前的状态记录；Windows Application 日志中未找到对应崩溃记录，无法据此确定退出原因。

将标题栏与网页从 Dock 布局改为明确的独立矩形区域，标题栏固定在网页上方。收起和关闭按钮增加宽度、深色粗体和背景色。收起逻辑改为隐藏完整日程窗口、显示独立的 54 DIP 桌面圆点窗口，避免缩小网页及原生子窗口；展开恢复日程窗口，圆点保持可拖动和右键退出。

状态文件增加进程 ID、两种窗口的可见状态及每五秒更新时间，并记录关闭原因，避免把旧文件当作进程仍然运行的依据。

验证覆盖标题栏在完整宿主中的命中检测、网页与标题栏不重叠、标题栏绘制截图、独立圆点的大小和桌面父级、窗口隐藏与展开、关闭按钮退出。既有 HTTPS 读取和自动刷新继续通过。上述测试不等同于用户桌面上所有窗口遮挡情况的验证。
