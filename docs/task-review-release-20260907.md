# 按任务填写复盘

用户要求的是完成任务后点击“查看复盘”填写该任务的复盘。本次移除之前误做的独立团队复盘输入区，任务行和“查看复盘”按钮直接打开原生弹窗，标题显示任务名称。

复盘记录存入 `tongpin-review-notes-v1`，每条记录必须带数值型 `taskId`。弹窗只显示当前任务的记录。保存继续使用服务器确认、冲突重试及失败保留输入的流程。

用户明确要求不保留旧的未关联任务记录；上线时清理了活动数据中的 1 条未关联记录，并检查即时历史副本。没有将该记录分配给任意任务，也未修改任务本身、邀请码或会话配置。

运行镜像：`tongpin-team-workspace:20260907-task-review`；发布目录：`/opt/apps/tongpin-team-workspace/releases/20260907-task-review`。HTTPS 地址及内部端口保持不变。

验证：生产构建、14 项自动测试及离线浏览器测试通过；公网 HTTPS 浏览器点击真实已完成任务的“查看复盘”，验证弹窗标题、填写和保存、刷新后重新打开，以及另一任务不显示该记录。临时验证记录已删除，测试会话已退出。

此记录取代 `review-release-20260907.md` 中独立团队复盘入口的说明；该文档的旧服务清理情况仍然有效。
