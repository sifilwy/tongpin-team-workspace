# 同屏日程组件

双击桌面的“同屏日程”图标打开；已打开时再次双击会展开并显示原窗口。关闭后也可用同一个图标重新打开，登录状态保留到网站会话到期。

- 点击任务旁的圆圈完成任务，再点一次恢复为未完成，保存后同步到网站。
- 鼠标滚轮或右侧滚动条浏览任务；点“单日 / 近三天”切换视角，点日历选择日期。
- 右上角 **−** 收起为蓝色笑脸圆点；点击圆点展开；**×** 退出组件。
- 拖动顶部空白处移动，拖动边缘或右下角斜线调整大小；Esc 取消这次拖动。位置和大小会保存。
- **•••** 或系统托盘菜单可刷新、恢复右侧位置或退出；双击托盘图标也能显示日程。
- 每 15 秒读取网站 xzx 的日程。完成操作保存期间暂时禁用按钮，避免重复点击；网络异常会显示未确认保存，可以刷新查看后重试。

新版使用普通独立窗口，不再嵌入 Explorer 桌面背景，不设置强制置顶。其他窗口可以覆盖它；Win + D 可能将它最小化，通过任务栏、托盘或桌面图标恢复。

此前桌面点击异常发生时系统记录了 Explorer 崩溃，尚不能证明唯一原因。新版已彻底删除桌面父窗口挂接与恢复逻辑，主窗口和圆点均为独立顶层窗口，不调用 SetParent，不与 Explorer 建立父子窗口关系。

程序保留本机已验证可用的软件渲染配置。首次使用或登录过期时输入网站邀请码；资料保存在 `%LOCALAPPDATA%/TongpinWidget/WebView2`，邀请码不写入源码或程序参数。程序不修改壁纸、不添加开机启动。

依赖 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。迁移时复制整个程序目录，保留三个 DLL。

构建：`node desktop-widget/build.mjs`，输出 `outputs/TongpinWidget`。WebView2 SDK 固定为 1.0.4191.47，附原许可证。

验证：`--verify` 使用独立资料目录，验证顶层窗口、拖动缩放、恢复窗口、页面同步、非黑屏画面、圆点展开及关闭，然后退出。`--signin-stdin` 仅用于可信本机验证，从标准输入读取邀请码，通过 HTTPS 登录；不得把邀请码放在参数中。验证报告不含任务正文、邀请码或会话。
